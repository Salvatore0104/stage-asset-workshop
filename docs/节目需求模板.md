# 可替换的节目需求模板

把下面文本中的 `【…】` 换成实际内容后发给 AI。暂缺信息写“待确认”，不要保留看起来像真实规格的默认值。

```text
请读取 https://raw.githubusercontent.com/Salvatore0104/stage-asset-workshop/main/INSTALL.md 并执行。

项目目录：【本机绝对路径】
节目名称：【名称】
英文代号：【例如 concert_intro】
总画布分辨率：【宽】×【高】像素
FPS：【25/30/其他正整数】
舞台遮罩：【PNG路径】，白色代表【成像/不成像】，是否使用透明通道：【是/否】
屏幕区域：【主屏/侧屏名称及 x,y,w,h；只有一块整屏写整屏】
PGM洞口：【无/文件路径及说明】
总时长：【秒数】
段落：【段名、秒数或拍数、是否循环、衔接说明】
音频：【路径/无】
音频描述：【曲风、情绪、重要段落、歌词或时间码】
BPM：【数值/待确认；如变速请附节拍表】
视觉风格：【主题、颜色、材质、年代、舞台参考】
设计稿/参考素材：【路径】
标题与副标题：【逐段文案】
生成模型：【默认采用当前工具配置/指定型号】
生成任务范围：【哪些段落、哪些屏幕】
部署仓库：【owner/节目仓库名/仅本地】
其他要求：【透明输出、分层、AE、版本等】

先建立并展示标准项目目录；用 Wowidea 生成按屏幕比例适配的素材；
随后构建简体中文工坊、验证并部署到指定仓库，记录任务ID和进度。
```

## 提示词里的自动变量

`show.json > generation.promptTemplate` 支持：

| 变量 | 自动替换来源 |
|---|---|
| `{{节目名称}}` | 节目名称 |
| `{{段落名称}}`、`{{段落提示}}` | 当前段落名称和视觉描述 |
| `{{屏幕名称}}` | 当前主／侧屏名称 |
| `{{屏幕宽}}`、`{{屏幕高}}` | 当前屏幕正式像素尺寸 |
| `{{屏幕比例}}` | 正式宽高约分结果 |
| `{{生成比例}}` | 实时模型支持的接近比例 |
| `{{时长秒}}` | 由秒数或拍数、BPM 计算 |
| `{{BPM}}` | 用户提供的 BPM |
| `{{风格}}` | 全节目视觉风格 |
| `{{文本}}` | 当前段落文案；建议网页独立排版 |
| `{{音频摘要}}` | 用户或制作人提供的音频描述 |

图片模型不会因为收到“30秒”就输出30秒视频；此变量只传达段落设计语境。时长由网页动画和后期序列控制。音频文件也不会直接传给不支持音频输入的图片模型，图片生成只使用音频文字摘要；需要音频驱动的视频须使用兼容视频工作流。
