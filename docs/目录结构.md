# 初始化后的标准目录

每个节目独立一个根文件夹。默认创建下列结构，并逐个放置 `目录说明.md`。初始化器不会把所有资料堆进素材工坊内部。

```text
我的节目/
├── 00_项目简报.md                  # 正式规格、输入来源、验收状态
├── 00_子对话说明.md                # 给下一个 AI 的交接入口
├── 项目目录说明.md                 # 本项目真实目录与用途
├── 制作方案.md                     # 风格、分层与动效方案
├── 进度.md                         # 完成、进行中、待确认、待验收
├── 成片ID记录.md                   # Wowidea Task/Canvas ID、采用素材及版本
├── AGENTS.md                       # 项目内 AI 入口规则
├── .agents/skills/stage-asset-workshop/SKILL.md
├── 01_分镜/                        # 分镜表、段落时长、时间码、转场
├── 02_参考素材/                    # 风格参考、素材来源、设计参考
├── 03_资产与需求/
│   ├── show.json                   # 【主要配置入口】
│   ├── 舞台遮罩.png                # 按实际输入文件名保留
│   └── 设计稿/                     # 后续存放 PSD/AI 等原稿
├── 04_输出交付/
│   ├── v日期_时间/web/
│   │   ├── index.html              # 【可打开/部署的节目工坊】
│   │   ├── workshop.html           # 同内容离线入口
│   │   ├── assets_001.js           # 有素材时自动产生分包
│   │   ├── 使用说明.txt
│   │   └── workshop-site.json      # 部署识别标记
│   └── 部署记录.json               # 发布后生成
├── 05_素材工坊/
│   ├── src/                       # 网页界面、引擎和分段动画
│   ├── tools/                     # HTML 构建、PSD 拆层、序列检查
│   ├── scripts/workshop.py         # 【一站式执行入口】
│   ├── docs/                      # 同包使用资料
│   ├── project.config.json         # build 从 show.json 产生，不手工双份维护
│   ├── .venv/                     # 安装时建立；不交付、不上传
│   ├── .tools/wowidea/             # 项目私有 CLI；不上传
│   └── .wowidea/                   # Canvas 绑定与运行记录；不公开发布
├── 06_音乐/                        # 音频原件、歌词、节拍、音频分析结果
├── 07_AE资产素材/
│   ├── 生成计划.json                # plan 产生，不会付费
│   ├── 模型能力.json                # 实时能力快照
│   ├── 请求/                       # 规范化图片生成请求
│   ├── 生成原件/                    # Wowidea 下载原件，不覆盖
│   ├── 适配素材/                    # 按每块屏幕像素生成的 PNG
│   ├── 生成记录/                    # 任务 ID、状态、比例、费用与诊断
│   └── PNG序列/                    # 正式分层输出时自行选择此处
├── 08_Blender工程/                  # 三维制作需要时使用
└── 99_归档/                         # 旧版本、弃用结果与备份
```

初始化时会创建九个编号主目录、根文档、配置及工坊源文件。`设计稿/`、生成记录、运行环境、版本网页等子目录按实际需要或命令执行创建，不伪造未制作的成果。

交付给 AE 的素材放 `07_AE资产素材`；交付给观看者或上传网页的成品放 `04_输出交付`。两个用途分开。原始音乐在 `06_音乐`，默认不随公开网页上传；要公开嵌入试听须明确设置 `audio.embedPreview=true`。

AI 完成初始化后应展示本机实际目录树，说明下一步把遮罩放哪里、在哪里改段落、从哪里打开网页、生成结果和任务 ID 保存在哪里。根目录文档不能只创建空标题后长期不更新。
