# show.json 配置说明

主要输入只有 `03_资产与需求/show.json`。构建器生成的 `05_素材工坊/project.config.json` 是派生文件，不要两边分别改参数。

| 字段 | 内容 |
|---|---|
| `id/name` | 英文节目代号／中文节目名称 |
| `stage.width/height` | 正式画布像素 |
| `fps/bpm` | 正整数幀率／正数 BPM；目前不支持 29.97 等有理数 FPS |
| `stageMask` | geometry 或全画布 PNG；图片使用 luminance／alpha 和 invert |
| `screens` | 各屏幕 id、name、x、y、w、h，全舞台像素坐标 |
| `pgm` | 默认关闭；开启时需提供独立 mask，并确认相关层确实挖洞 |
| `style/palette` | 全节目风格文字及颜色 |
| `audio` | 原音频路径、试听起点、文字摘要、是否随网页嵌入 |
| `generation` | 图片模型、支持的分辨率、maxJobs、cover/contain、参考及提示词模板 |
| `parts` | 段落 ID、名称、seconds/beats 时长、loop、text、subtitle、prompt、backgrounds |

所有 show.json 的素材路径相对**节目根目录**，不是相对 JSON 所在的需求目录。生成器会自动把它们转换成构建配置路径。导入文件保留原件名。

`parts[].backgrounds` 以屏幕 ID 指向适配后图片；自动生成完成会写回。也可以直接填入自己制作的合法图片路径，跳过 `generate` 直接 `build`。`parts[].textScreen` 指定标题放在哪块屏，默认寻找 `main`。

`audio.embedPreview=false` 时不会把音频打包到公开站点，在网页选择本地音频试听。若明确要公开嵌入，改为 `true`，支持 MP3/WAV/OGG/M4A；音频会成为网页媒体包的一部分。播放器按照段落累计时长、BPM 和 `offsetSeconds` 同步试听；BPM 需要用户指定，工具不自动识别节拍，也不变速拉伸音乐。WebM 预览无音轨。

网页修改标题／副标题只影响当前打开的工坊，刷新会恢复构建值；“下载当前设置”得到运行时设置 JSON，交给 AI 将需要的修改写回 show.json，再重新构建。

模型返回的图片比例和舞台正式尺寸分开记录。舞台遮罩始终按正式尺寸核对，不为适应模型而修改原始遮罩。多边形形状及矩形取联集，复杂带洞曲线优先使用 PNG。
