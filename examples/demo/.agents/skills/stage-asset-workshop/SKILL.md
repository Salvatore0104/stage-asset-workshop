# 节目素材工坊

先读项目根目录 `00_项目简报.md`、`项目目录说明.md`、`03_资产与需求/show.json`。尚未初始化时，读工具仓库 `INSTALL.md` 并运行 `scripts/install.py`。网页及项目说明使用简体中文。

## 输入与目录

正式宽高、FPS、遮罩语义、PGM 有无和段落时长影响交付结果，无法从文件确认时集中询问；其余先推进。无遮罩时只能作为全画布样机，不宣称已完成真实舞台对位。段落、参考、需求、音乐、源代码和交付分别进入标准编号目录。细节见工具包 `docs/目录结构.md`。

运行器在 `05_素材工坊/scripts/workshop.py`；Python 优先用 `05_素材工坊/.venv`。从项目根目录执行 `plan → generate → build`；用户要求发布时再执行 `deploy`，或使用带 `--repo owner/name` 的 `all`。工具仓库的同名脚本也支持 `--project 项目路径`。

## 生成

先读 `05_素材工坊/docs/Wowidea.md`。如环境提供 Wowidea 技能，也读该技能及所选模型的提示词指南。没有技能时，阅读已安装 `@easyai/cli/skill/wowidea/SKILL.md` 和指南。模型能力以实时查询为准；脚本只支持已验证的图片生成流程，AI 视频按 Wowidea 当前官方 CLI 工作流另做，再逐帧适配。

`plan` 不付费，只生成逐段逐屏任务。检查提示词、参考角色、原生比例与正式尺寸是否一致。**本工具按用户选择采用 Wowidea CLI `--direct`，不使用 Canvas，不要求 Canvas OAuth。**本地准备使用 `project setup --no-canvas`；随后逐项提交一次。原件保留，采用 `cover/contain` 适配。比例不符、认证失败或任务状态不明时停止并报告原任务，不自动重投、换模型或改走网站 UI。需要恢复时只恢复原任务。任务记录在 `07_AE资产素材/生成记录`，摘要写根目录 `成片ID记录.md`。

生成后查看实际图片再判断质量；交付下载素材、任务 ID 和可用费用。direct 模式没有 Canvas 链接，不启动画布或外部浏览器。CLI API 认证不足时说明真实诊断，不能把未生成的渐变占位图当作 Wowidea 成果。

## 制作与交付

`show.json` 负责正式规格、分屏、时长、音频、文案和提示词占位符。静态背景、标题、特效、舞台 matte 与可选 PGM matte 分层输出。复杂编排依设计稿扩展 `05_素材工坊/src/scenes.js`，先静态对位再动画。不要把默认粒子与标题样机描述为完成全部创意制作。

`build` 输出 `04_输出交付/<版本>/web/index.html`，可本地打开；音频默认不嵌入，可在网页本地选择试听。网页包含本地代码与采用的素材，不包含 Wowidea 认证、任务原始记录或音频原件。正式导出沿用同尺寸透明 PNG、静态单张和动态序列规则；需在原解析度、真实遮罩和 AE 工程重新验收。

用户明确要求部署后，`deploy --dir 网页目录 --repo owner/name` 只上传构建产物到指定仓库的 `gh-pages`，不公开整个节目源文件夹。等待并检查 Pages 的实际构建状态和 HTTP 页面；推送成功不代表上线。记录网址、版本及未验证事项，更新 `进度.md` 与 `00_子对话说明.md`。
